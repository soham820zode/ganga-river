# 1. CORE ENGINEERING PRINCIPLES

Always follow these principles.

## Principle 1 — Never fabricate science

The application may use simulated/demo data.

However:

* never claim simulated readings are real sensor measurements
* never claim simulated forecasts are scientifically validated
* never fabricate research findings
* never invent government certifications
* never invent sensor deployments
* never invent model accuracy
* never invent pollution causes
* never claim official Water Quality Index calculations unless an authoritative methodology is actually implemented

Whenever simulation is being used, clearly identify it.

Preferred labels:

DEMO DATA

SIMULATED DATA STREAM

PROTOTYPE FORECAST

DEMO COMPOSITE INDICATOR

PROTOTYPE REFERENCE THRESHOLD

---

# 2. ENGINEERING PRIORITY

When making implementation decisions, prioritize in this order:

1. Correctness
2. Data integrity
3. Maintainability
4. Performance
5. Accessibility
6. Responsive behavior
7. Visual quality
8. Animation

Never sacrifice application correctness for visual effects.
